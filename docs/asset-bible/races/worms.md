## 1. Стилевая формула

Колония гигантских кольчатых червей: всё построено из одного элемента — сегмента
тела с хитиновыми кольцами, костяными когтями и глянцевыми глазами. Здания — это
клубки, курганы и норы из сросшихся червей; корабли — сами черви, ощетинившиеся
шипами. Ни одной рукотворной поверхности: никакого металла, панелей, стекла.

## 2. Геометрический язык

| Параметр | Значение |
|---|---|
| Базовые формы | сегментированные трубы (тела червей), клубки и мотки, конические когти и шипы, сферические глаза-бусины, куполообразные курганы |
| Углы и фаски | углов нет; всё либо цилиндрическое, либо коническое, либо сферическое |
| Симметрия | радиальная у зданий (клубок вокруг устья), билатеральная у кораблей (голова с челюстями — хвост) |
| Панелизация | заменена кольчатостью: поперечные кольца сегментов |
| Гриблы | когти, шипы, глазные бусины, зубчатые венцы вокруг пасти |
| Запрещено | плоскости, прямые углы, металл, стекло, любой видимый крепёж |

Здания: 4 орбитальных дока, 2 орбитальных щита, 3 наземных кинетика,
Colony Base, 3 фабрики, 3 орбитальных кинетических шара, 3 фермы, 3 лаборатории,
3 жилых норы, электростанция, Science Hive Mind, Living La Vida Loca.

Корабли: 15 готовых корпусов (Small/Medium/Large/Huge × Segmented/Claw/Hive Mound
/Sponge) плюс кит деталей — `Body_Segment_Eye_Orb` ×3, `Body_Segment_stix` ×12
(шипы), `Body_Segment_Jaws` ×3, `Body_Segment_torro`.

## 3. Палитра

Снята с референс-листов. Ключевое наблюдение: насыщенность там **ниже**, чем
подсказывает интуиция от слова «коричневый хитин» — около 0.19 по шкале
`(max-min)/max` против 0.26 у первой прикидки, поэтому все тона сдвинуты
к нейтральному. Здания теплее (налипшая земля), корабли — тот же хитин, но
холодный и на тон светлее (выветренный камень).

## 4. Как проставлены зоны

Никакой семантики в мешах нет (у узлов даже `extras` пустые), поэтому зоны
выводятся из геометрии:

* **`medial radius`** — усадка касательного шара («shrinking ball») даёт
  полутолщину тела под вершиной. Тонко → коготь/шип → кость; толсто → корпус →
  хитин. Работает на этих мешах именно потому, что не требует замкнутости:
  каждая модель — сотни несшитых оболочек.
* **`occupancy AO`** — размытая воксельная заполненность, снятая чуть над
  поверхностью. Замуровано → щель, нутро пасти → тёмный хитин.
* **`sphere fit`** — шар, сидящий на существенно большей оболочке, это глаз.
  Дополнительная проверка «покрытия» отсекает округлые навершия (купол трубы
  фабрики агрегирует тот же центр, но закрывает лишь полусферу).
* **имена узлов** — кит кораблей сам подписывает свои детали
  (`..._Eye_Orb` → целиком глаз, `..._stix` → целиком кость), а двум орбитальным
  щитам и `Living_La_Vida_Loca` свечение назначается адресно.

Известное ограничение: земляные комки вокруг `Hive_Dwelling` геометрически
неотличимы от глаз — это один и тот же шар. Несколько крапин там остаются
фиолетовыми; против референса, где комки тоже в тёмную крапинку, читается
нормально.

Тонкое и **длинное** костью не становится: труба фабрики проходит по толщине,
но её «тонкая» связная область тянется через всю модель, и фильтр коротких
выступов возвращает её в хитин.

## 5. Перезапуск

```bash
python3 tools/paint_worms_constructors.py \
    ~/.ascendancy/assets/races/worms/buildings/worms_building_constructor.glb \
    /tmp/worms_buildings.glb --kit buildings --report
python3 tools/preview_constructor_kit.py /tmp/worms_buildings.glb /tmp/sheet.png
```

Инструмент идемпотентен по геометрии, но **не** по материалам: он ожидает
исходный однопримитивный экспорт. Повторный прогон по уже покрашенному файлу
переразобьёт примитивы заново — результат тот же, но размер файла подрастёт.
Нужны numpy + scipy + pillow, Blender не требуется.
