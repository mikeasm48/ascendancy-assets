# Референсы кораблей — что сюда класть

> **Оригиналы:** полноразмерные версии лежат вне репозитория —
> `~/java/ascendancy-refs-originals/ships/`. Здесь хранятся ужатые копии
> (≤1024px, JPEG q85) — их достаточно для сверки силуэтов и палитры при
> сборке кита. Для генерации GLB эта папка не нужна.

Раскладка — по расам, подпапка на расу. Внутри — по классу корпуса,
теми же четырьмя размерами, что и в игре: `Small`, `Medium`, `Large`,
`Huge`.

| Папка | Файлов | Что есть | Статус расы |
|---|---|---|---|
| `Bulls/` | 5 | 4 корпуса + фон орбитального дока с кораблём | нет в `Race`; в ассетах только `bulls/orbital_dock/` |
| `Chronomist/` | 4 | 4 корпуса | нет в `Race`, ассетов нет |
| `Comanches/` | 6 | 4 корпуса + лист деталей + фон дока | есть в `Race`; в ассетах только `comanches/orbital_dock/` |
| `Cyber/` | 4 | 4 корпуса | нет в `Race`, ассетов нет |
| `Dubtaks/` | 7 | 4 корпуса + корпуса-развёртка, лист деталей, гриблы Huge | нет в `Race`, ассетов нет |
| `Worms/` | 18 | 4 корпуса + 4 семейства силуэтов (Ship / Claw / Hive Mound / Segmented) × 3 размера + лист деталей + био-док с кораблём | нет в `Race`; кит собран — см. `../../races/worms.md` |

## Именование

`<Раса>_<Класс>.jpg` для корпусов (`Worms_Huge.jpg`, `Cyber_Small.jpg`),
`<Раса>_Ship_<Семейство>_<Класс>.jpg` для вариантов силуэта
(`Worms_Ship_Segmented_Large.jpg`). Пробелов в именах не держим —
подчёркивания, как в остальных папках `refs/`.

## Лист деталей — самый ценный файл

`*_Ship_Parts.jpg` (есть у Worms, Comanches, Dubtaks) — разложенный кит:
носовые секции, сегменты корпуса, глаза, когти, гребни плюс примеры сборки.
Именно он, а не отдельные корпуса, служит эталоном **палитры**: цвета
сняты пиксельно с его сводных плашек. Для Worms так и сделано (см.
`races/worms.md`, §3).

## Формат

- **Лучше всего:** плоский рендер или концепт, вид ¾, объект на нейтральном фоне.
- Ужимаются в JPEG, поэтому прозрачность теряется — альфа сводится на белый.
  Если прозрачность важна, оригинал всё равно остаётся в
  `ascendancy-refs-originals`.
- 3D-модель (GLB/OBJ) в этой папке не хранится: либо `*_preview.png`, либо
  рабочий исходник рядом с генератором (как `buildings/Shuffie/*.glb`).
